🎯 What you need to be able to do

Solve a pair of simultaneous equations where one is linear (a straight line) and one is quadratic (a curve), using substitution. Each pair has two answer points — find both, and give each as an (x, y) pair.

📋 Method steps — keep this in view

Method steps — refer back to this while you work:

  1. Step 1: Make y the subject of the straight-line (linear) equation.
  2. Step 2: Substitute that into the curve (quadratic) equation.
  3. Step 3: Move everything to one side so the equation equals 0.
  4. Step 4: Solve the quadratic — factorise, or use the formula.
  5. Step 5: Put each x back in to find its y. Write your answers in pairs and check them.

✏️ Worked example

Solve:  y = x² − 2x + 3   and   y = x + 3

Step 1–2: The line already gives y, so substitute:  x² − 2x + 3 = x + 3
Step 3: Move to one side:  x² − 3x = 0
Step 4: Factorise:  x(x − 3) = 0  →  x = 0 or x = 3
Step 5: Find y from y = x + 3:  when x = 0, y = 3;  when x = 3, y = 6

Answers:  (0, 3)  and  (3, 6)
