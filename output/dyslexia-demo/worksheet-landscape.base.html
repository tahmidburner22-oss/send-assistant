Quadratic Simultaneous Equations AQA Higher · Grade 8–9
Solve each pair. Show your working and answers in your workbook.

Method

1 Make y the subject of the straight line2 Substitute into the quadratic3 Rearrange so it = 04 Solve (factorise or formula)5 Find each pair (x, y) and check

Common mistakes

  • There are usually two answers, not one — find both x values, e.g. x = 3 and x = −1.
  • Get everything on one side so it = 0 first, e.g. x² = 2x + 3 becomes x² − 2x − 3 = 0.
  • Watch minus signs: (x − 1)² = x² − 2x + 1, not x² − 1.
  • Each x has its own y — put x back in to find y.

Worked example

Solve: y = x² − 2x + 3 and y = x + 3
Step 1 — Make y the subject of the line: y = x + 3
Step 2 — Substitute into the quadratic: x² − 2x + 3 = x + 3
Step 3 — Rearrange so it = 0: x² − 3x = 0
Step 4 — Solve (factorise): x(x − 3) = 0 → x = 0 or x = 3
Step 5 — Find each pair (x, y) and check: (0, 3) and (3, 6)
