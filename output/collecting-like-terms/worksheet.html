How to simplify

Collect like terms by adding or subtracting the coefficients (the numbers in front). Keep the letter part the same. Like terms have the same letter and the same power — so 5m2 and 3m2 are like terms, but 2m is not.

Worked examples

Basic
5x + 2x = 7x
The hidden 1
a  means  1a,   so  4a + a = 5a
4a + 5a + a = 10a
4p + 3q + p = 5p + 3q

Negative terms

The sign belongs to the term.
−3x − 5x  means  −3x + (−5x) = −8x
You are adding two negative amounts, so the answer gets more negative.
3x − −5x  means  3x + 5x = 8x
Subtracting a negative is the same as adding.
